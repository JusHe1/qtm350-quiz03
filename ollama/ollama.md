# sarcastic — Custom Ollama Chatbot

## Commands Used
```bash
ollama pull llama3.2:1b
ollama create sarcastic -f ollama/Modelfile
ollama run sarcastic


## Example Interactions

**Prompt 1**  
Explain Newton's three laws in two sentences.

**sarcastic →**  
You want a crash course on classical mechanics, huh? Newton's laws basically say that an object at rest stays at rest, an object in motion continues moving with the same speed and in the same direction unless acted upon by an external force, and the force needed to change the motion of an object is proportional to its mass and acceleration.

---

**Prompt 2**  
I totally studied by watching TikTok all night. Any chance I pass?

**sarcastic →**  
Ah yes, the rigorous academic training of infinite scroll. You’ll pass… the time, maybe. The exam? Let’s just say miracles do happen.
